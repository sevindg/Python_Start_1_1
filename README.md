# 🐍 Питончик — веб-тренажёр Python для детей

Интерактивный тренажёр по программированию на Python: тест по слайдам, практика кода с автопроверкой, подсказки и сертификат. Python-код выполняется прямо в браузере (библиотека Skulpt).

Сделано на React + TypeScript + Vite + Tailwind CSS.

## Запуск на своём компьютере

Нужен [Node.js](https://nodejs.org) (версия LTS).

```bash
npm install
npm run dev
```

Откройте в браузере http://localhost:3000

> ⚠️ Файл `index.html` нельзя открывать двойным щелчком — страница будет пустой.
> Проект нужно запускать через `npm run dev` или собрать командой `npm run build`.

## Сборка

```bash
npm run build     # готовый сайт появится в папке dist/
npm run preview   # посмотреть собранную версию
```

## Публикация на GitHub Pages

Публикация настроена автоматически (`.github/workflows/deploy.yml`):

1. Загрузите проект в репозиторий на GitHub (ветка `main`).
2. В репозитории откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
3. После каждого изменения в ветке `main` сайт пересобирается сам и доступен по адресу
   `https://<ваш-логин>.github.io/<имя-репозитория>/`
